# 旧版操作手册（历史文档）

当前升级版请阅读项目根目录操作手册.md。本文件保留用于对照旧版行为。

## 1. 准备环境

1. 连接 USB 外置摄像头，避免同时打开会议软件或系统相机。
2. 在项目目录创建 Python 虚拟环境并安装依赖：

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

3. 执行 `python main.py`。若操作系统询问相机权限，请选择允许。

Windows 激活命令为 `.venv\Scripts\activate`。Linux 若提示没有 Tkinter，请通过系统包管理器安装 `python3-tk`。

## 2. 选择外置摄像头

1. 主界面右侧“设备”区域会自动扫描索引 0–5。
2. 优先选择“外置优先 1”；若它没有画面，停止后依次尝试其他索引。
3. 点击“启动实时比对”。标题右侧显示设备索引，左侧显示实时画面。
4. 需要插拔设备时，先点“停止摄像头”，插拔后点击“刷新”。

## 3. 建立不少于三类人员的标准库

对每个人重复以下步骤：

1. 只让一张人脸进入画面，距离约 0.5–1.2 米。
2. 输入姓名，保持正脸，点击“采集当前人脸”。
3. 轻微向左、向右转头，并改变一次自然表情，累计采集 5 张。
4. 若提示过暗、过曝、模糊或距离过远，改善环境后重新采集。
5. 点击“保存入库”。系统保存样本并自动校准阈值。

同名录入会给已有人员追加样本，不会新建重名类别。新人员至少需要 3 张，推荐 5–10 张；每人的拍摄条件应有适度差异，但不要录入严重模糊或遮挡图像。

## 4. 实时比对

1. 已录入人员进入画面后，先看到“正在确认”，达到多帧多数后显示姓名与“比对通过”。
2. 未录入人员、超过阈值的人员、前两名过于接近的人员均显示“未知人员 / 比对不通过”。
3. 绿色框表示已知匹配，红色框表示未知，黄色框表示质量不足。
4. 右侧会同时显示相似度、卡方距离、当前阈值和质量指标。判定实际使用“距离不超过阈值”，相似度用于直观展示。

## 5. 标准库扩容与阈值重算

- 新增人员：输入新姓名，采集至少 3 张后保存。
- 追加样本：输入完全相同的已有姓名，采集至少 1 张后保存。
- 手工校准：点击“自动校准阈值”；当不同身份不足 2 类或同人配对不足时，系统明确使用默认阈值。

建议所有人员录完后再点一次“自动校准阈值”，并使用独立测试图片检查误接收率和拒真率。

## 6. 静态图片批量命令

```bash
python -m face_compare.cli enroll --name "人员A" sample/a1.jpg sample/a2.jpg sample/a3.jpg
python -m face_compare.cli recognize test/known.jpg test/unknown.jpg
python -m face_compare.cli recognize --json test/*.jpg
python -m face_compare.cli list
python -m face_compare.cli calibrate
python -m face_compare.cli cameras
```

批量录入时，每张图片必须恰好含一张人脸；坏图会被跳过并给出原因。若全部被拒绝，命令以非零状态退出。

## 7. 推荐测试记录

准备不参与录入的测试样本，并记录：

| 场景 | 建议次数 | 预期观察 |
|---|---:|---|
| 已知人员正常光正脸 | 每人 10 次 | 姓名正确、稳定通过 |
| 未知人员 | 至少 3 人×10 次 | 返回未知 |
| 暗光 / 逆光 / 过曝 | 各 10 次 | CLAHE 改善或质量门控拒绝 |
| 轻微左右转头 | 每人各 10 次 | 侧脸检测提升召回 |
| 戴普通眼镜 | 每人 10 次 | 对比正常场景准确率 |
| 运动模糊 / 距离过远 | 各 10 次 | 明确提示质量不足 |

从混淆矩阵计算准确率，并单独报告：误接收率 FAR = 未知人员被错误接受次数 / 未知测试总数；拒真率 FRR = 已知人员被拒绝次数 / 已知测试总数。用 `time.perf_counter()` 或录屏计时统计平均响应时间。

## 8. 常见故障

- “无法打开摄像头”：关闭占用相机的软件，允许系统权限，刷新后改选索引。
- 一直检测不到：正对镜头、提升正面照明、缩短距离，必要时将 `min_face_pixels` 从 80 调低到 60。
- 经常把已知判未知：补充多角度清晰样本，再自动校准；确认不是质量门控导致。
- 经常把未知判已知：减小距离阈值、增大 `ambiguity_margin`，并清理错误或过于相似的录入样本。
- UI 无中文但可运行：系统未安装苹方字体，Tkinter 会自动使用默认字体，不影响算法。
- Linux 缺少 Tk：安装发行版的 `python3-tk` 后重试。

## 9. 数据清理与隐私

停止程序后，可删除 `data/people.json`、`data/features/` 和 `data/samples/` 清空人脸库，删除 `logs/events.jsonl` 清空日志。删除不可撤销，先确认不再需要实验数据。采集、保存和演示人脸前应取得本人同意，不要将 `data/` 或 `logs/` 提交到公开仓库。
