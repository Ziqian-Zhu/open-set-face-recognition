# 固定配对的采集失败诊断与人员分组统计

日期：2026-09-26。主 run：[meglass-acquisition-diagnostics-20260926-01](results/meglass-acquisition-diagnostics-20260926-01/metrics.json)。本轮没有重新下载数据、打开相机、修改主程序或读取既有人员库。它补上了原 1:1 实验“111 组失败却不知道在哪一步”的缺口，不是识别准确率提升实验。

## 协议与不变性

基线为 `meglass-verification-20260926-01`，仍用原 validation/test 各 200 人、400 张图、300 组配对。配置、模型、完整清单哈希必须与基线一致；复用已冻结的 τ=0.3561805486679077，不重新校准，不替换失败图，不根据本轮分数选模型或门槛。诊断计划见 [固定诊断协议](protocols/verification_diagnostics_v1.json)。

`acquisition.py` 对隔离实例临时包装检测、裁剪、质量、对齐和提取方法，**调用正式 `prepare_sample` 一次**，不复制另一套处理流程；离开上下文或安装中途失败都会恢复实例方法。检测失败或画质拒绝后，不偷偷提取特征，也不推断下游是否本来会识别正确。

validation/test 全部 **600 组配对**的图像哈希、真值、状态和距离与原基线逐项完全一致，否则拒绝发布。800 张不同图像按解码哈希去重；同一图片同时用于同人/异人配对，只在图像级统计里计一次。不同哈希不证明拍摄事件独立。

输出五项可校验产物：`metrics.json`、`experiment_config.json`、`diagnostic_plan.json`、`images.csv`、`pairs.csv`，另保留运行日志。共享日志中的 `frozen_validation.json` 此处装的是明确标注为 `posthoc-diagnostic-plan-v1` 的事后诊断计划，**不是新一轮盲测阈值标定**。

## 1. 测试集失败发生在哪一步

| 以400张不同图像为分母 | 戴镜200张 | 摘镜200张 | 总计 |
| --- | ---: | ---: | ---: |
| 检测路径无有效人脸输出 | 30 | 35 | 65 |
| 质量门控拒绝 | 27 | 42 | 69 |
| 可用、完成对齐和特征提取 | 143 | 123 | 266 |
| 对齐或特征提取阶段失败 | 0 | 0 | 0 |

`no_face` 是正式检测器经过内部过滤后的空输出，不等同于已证明 YuNet 网络完全没有候选；它也可能包括尺寸/关键点等内部过滤。当前不能进一步把这 65 张全部归因为模型漏检。

69 张质量拒绝图中：模糊规则触发 **65 张**（戴镜24、摘镜41），过暗5张、低对比度7张。原因可以重叠，不能把 65+5+7 当作拒绝图片数。分区细节、亮度、对比度等原始质量测量在匿名哈希 CSV 内保留；这些统计不触发自动放松规则。

以200组同人配对为分母，111组采集失败互斥分解为：

- 49组：失败侧只有无有效检测问题。
- 53组：失败侧只有画质拒绝问题。
- 9组：一侧无有效检测，另一侧画质拒绝。

按两侧是否可用分解：89组两侧可用，54组仅戴镜图可用，34组仅摘镜图可用，23组两侧都不可用。89组可用中仍是88组接受、1组拒绝，全部尝试接受率仍为88/200，不隐去前端失败。

这定位了**该批裁剪图**的主要损失位置，但不是眼镜因果实验。两种外观的照片可能有不同姿态、光照、拍摄时间与清晰度；不能直接得出“摘镜导致画质模型歧视”或“关闭模糊规则安全”。先前53组质量失败也不能推断为53组必可正确识别，因为本轮没有绕过门控测其距离。

## 2. 人员分组统计，而不是假定所有pair独立

新增 `evaluation/grouped.py`：以人员为节点、配对为边，先求共享人员连通分量，再整组有放回重采样。这样一个人参与同人和异人配对时，不会被拆成独立试验。当前每个split有100个分量，每组2人、3个pair；固定seed=20260926，2,000次重采样。所有失败保留在全尝试分母中。

报告不同人员等权的 genuine macro 比例；本协议每人恰好一组 genuine，因此test的macro与全部尝试比例都为44%，不会额外制造更高成绩。

| test统计 | 原始计数 | 分组重采样描述性95%区间 |
| --- | --- | --- |
| genuine接受／全部尝试 | 88/200，44.0% | 37.0%–51.0% |
| genuine接受／可用配对 | 88/89，98.88% | 96.34%–100% |
| genuine采集失败 | 111/200，55.5% | 48.5%–62.0% |
| 原冻结阈值相对固定工程τ=0.275的全尝试TAR差 | +10/200，+5个百分点 | +2至+8个百分点 |

最后一项是同一批pair、同一组抽样下的配对差值，**不是新模型效果或新调参结果**；工程τ原本服务于1:N，不能因1:1描述性差值自动替换线上设置。

0/44 impostor误接的bootstrap会退化为全零；代码明确输出 `percentile95=null`、`degenerate_resamples_no_risk_bound`，不报告看似精确的[0,0]安全保证。原Wilson描述性上界约8.03%以及低FAR样本不足的结论保持。

这些区间固定基线阈值，不包含阈值标定不确定性；人员连通分组也无法修复缺失拍摄会话、源标签错误、预训练重叠或样本选择偏差。最少20个分量只是软件报告门槛，不是独立性保证；样本不足、无分母、重采样出现空分母或退化时会明确停报区间。
